# unsolved-problems · 未解之题

算法竞赛题解仓库。

每道题一个目录，目录内三份文件（题面 / 题解 / 代码分开存放）：

```
<题目目录>/
├── problem.md     # 题面（含输入输出格式、数据范围、样例、题目来源）
├── solution.md    # 解题思路（含推导、证明、复杂度分析）
└── main.cpp       # 高可读性 AC 代码（可直接提交 OJ）
```
