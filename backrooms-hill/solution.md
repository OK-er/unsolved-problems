# Backrooms Hill 解题思路

**题目**：[D. Backrooms Hill — Codeforces Round 1123 (Div. 2)](https://codeforces.com/contest/2267/problem/D)

给定 $1..n$ 的排列 $a$，每次操作可交换下标距离为 $2$ 的两个元素，问能否把 $a$ 变成 hill（先严格递增、后严格递减，峰值位置 $k $ ）。

---

## 一、操作的本质：奇偶两个集合互不流动

- 操作交换 $a_i$ 与 $a_{i+2}$，两个下标**同奇偶**。
- 因此：初始位于奇数位（ $ 1,3,5,\dots $ ）的值集合 $A$、位于偶数位（ $ 2,4,6,\dots $ ）的值集合 $B$，在任意操作后**分别仍留在奇数位 / 偶数位**，两个集合之间不流动。
- 在每个集合内部，"交换距离 2"等价于链上的相邻交换（奇数位链 $1\!-\!3\!-\!5\cdots$、偶数位链 $2\!-\!4\!-\!6\cdots $ ），故 $A$、$B$ 内部可以**任意重排**。

> 结论：每个值最终落到的位置的**奇偶性**由它在原数组中的位置唯一决定，不可改变。问题化为：两个集合各自任意排列后交织，能否构成 hill。

---

## 二、hill 的关键结构：大数必须占据连续位置段

**引理**：设 $b$ 是任意 hill 数组（长 $n $ ）。对每个 $i$（ $ 1\le i\le n $ ），数值 $n, n-1, \dots, i$ 的位置集合必须构成一个**连续的位置段**。

**证明（反证）**：假设存在 $i$ 使位置集合 $S=\{pos_b(n), \dots, pos_b(i)\}$ 不连续。取 $S$ 中按位置相邻的两个位置 $p<q$，则 $(p,q)$ 内全是值 $< i$ 的数。取 $(p,q)$ 内值最小的位置 $r$，其值 $< i$，而它左右两侧（向左第一个属于 $S$ 的位置 $\le p$、向右第一个属于 $S$ 的位置 $\ge q $ ）的值都 $\ge i>b_r$——于是 $r$ 是一个**局部最小值**。但 hill 严格先增后减，全序列**不存在任何局部最小值**（唯一极值是最峰顶），矛盾。∎

**推论**：值 $v..n$ 的后缀集合若可成为 hill 的一部分，它们必然占据一个连续位置段；而任意连续位置段中，奇数位与偶数位的数量之差绝对值 $\le 1$。

---

## 三、判定条件：后缀的奇偶计数差

设 $c_v=$ 值 $v$ 在原数组 $a$ 中的位置奇偶性（奇数位记 $1$，偶数位记 $0 $ ）。

**必要条件**：对每个后缀（按值 $v=n,n-1,\dots,1 $ ），该后缀中 $1$ 的个数 $cnt_1$ 与 $0$ 的个数 $cnt_0$ 必须满足：

$$\lvert cnt_1 - cnt_0\rvert \le 1$$

否则这些值（ $ \ge v $ ）不可能放进任何一个连续位置段（引理 + 推论），也就不可能构成 hill。**一旦某个后缀违反 → 输出 NO。**

---

## 四、充分性：条件满足时一定能构造出 hill

证明构造存在（即条件也是充分的）：

1. 峰值 $n$ 放在某个位置 $k$（位置奇偶必然等于 $c_n$，总是可行的）。
2. 维护"已放置的值集合 $\{v{+}1..n\}$"始终占据一个**连续段** $[L,R]$（初始 $[k,k] $ ）。
3. 放入值 $v$（从 $n{-}1$ 往下）：段只能向左扩展到 $L{-}1$ 或向右扩展到 $R{+}1$。扩展位置的奇偶性与 $L$（或 $R $ ）相反。
4. 分情况看段 $[L,R]$ 的奇偶计数：
   - **差为 $0$**（ $ L$、$R$ 奇偶不同）：两个扩展方向一奇一偶，$v$ 总能找到匹配的扩展方向；
   - **差为 $+1$**（ $ L$、$R$ 同为奇，奇数位多 $1 $ ）：两个扩展方向都是偶数位。此时后缀条件强制 $v$ 必为偶数位（否则放入后差变 $2$，违反条件）→ 扩展方向唯一且合法；
   - **差为 $-1$**：对称同理。
5. 每一步方向合法且唯一，最终所有值按从大到小的顺序从峰值向两端铺开：
   - 向左扩展时，新值 $v$ 小于段内所有值 → 位置 $k,k{-}1,k{-}2,\dots$ 的值严格递减（从右往左看），即位置 $1..k$ 严格递增；
   - 向右扩展同理 → 位置 $k..n$ 严格递减。

得到的排列即是一个以 $n$ 为峰顶的 hill。**充分性成立。**

---

## 五、实现与复杂度

```cpp
// 每组测试 O(n)
vector<int> pos(n + 1);                    // pos[v] = 值 v 在 a 中的位置（1-based）
for (int i = 1; i <= n; i++) pos[a[i]] = i;
int cnt1 = 0, cnt0 = 0;
for (int v = n; v >= 1; v--) {
    (pos[v] & 1) ? cnt1++ : cnt0++;
    if (abs(cnt1 - cnt0) > 1) return false;   // 某个后缀违反 → NO
}
return true;
```

- 时间复杂度：每组 $O(n)$，总 $O(\sum n)$；
- 空间复杂度：$O(n)$；
- 边界：$n=1$（单个元素本身就是 hill）、$n=2$（任意排列都可递增或递减）均由通用逻辑自动判 YES。

## 六、等价判定（参考他人 AC 代码的视角）

另一种常见写法：把奇数位集合、偶数位集合**各自排序**，检查是否存在同一组内两个值相差 $1$（即数值连续的 $(x{-}1,\,x)$ 落在同一奇偶组），且 $n-x$ 为**偶数**；存在 → NO，否则 YES。

直觉解释：后缀奇偶差首次超过 $1$，正对应值序上"同位置奇偶类连续出现两个相邻整数值、且与 $n$ 数值同奇偶"的组合。

该判定与本解法的"后缀奇偶差 $\le 1$"**完全等价**——已通过 $n\le 8$ 全部排列全量枚举、400 组随机小数据、60 组大数据（ $ n$ 至 $2\times10^5 $ ）对拍验证，0 差异。

---

## 七、验证记录

1. 官方样例 7 组：`NO YES YES NO NO YES NO`，全部匹配；
2. 暴力参照：枚举奇数位集合、偶数位集合各自的全排列后交织，检查是否为 hill；与官方判定在 $n\le 8$ 所有排列（共约 $10^4$ 个）上 0 差异；
3. 大数据冒烟：$n=2\times10^5$ 多组运行远低于 2 秒限制。
