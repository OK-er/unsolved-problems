# M - Brackets

- 来源：[2026牛客暑期多校训练营10](https://ac.nowcoder.com/acm/contest/133885) · M 题（[题目页](https://ac.nowcoder.com/acm/contest/133885/M)，重现赛见 [140941](https://ac.nowcoder.com/acm/contest/140941/M)）
- 标签：贪心 / 线段树 / 括号序列 / 前缀和
- 难度：困难（官方难度表：M）

## 题目描述

给定两个**正则括号序列**（regular bracket sequence）`S`、`T`，长度均为 `n`，以及两个整数数组 `a`、`b`。

> 括号序列称为正则的，如果在其字符之间插入 `1` 与 `+` 可以变成一个合法的算术表达式（即：标准合法括号序列，前缀和恒非负且总平衡）。

序列 `P`（长度 `n`）的**权重**定义为：

- 对每个满足 `P_i = (` 的位置 `i`，加上 `a_i`；
- 对每个满足 `P_i = )` 的位置 `i`，加上 `b_i`。

即 `weight(P) = Σ_{P_i=(} a_i + Σ_{P_i=)} b_i`。

对每个整数 `k`（`0 ≤ k ≤ n`）：**恰好选择 `k` 个位置**，在每个被选位置 `i` 把 `S_i` 替换成 `T_i`。记结果序列为 `S'`。在所有使 `S'` 仍为正则括号序列的选择方案中，求 `weight(S')` 的最大值。

若对某个 `k` 无法得到任何正则括号序列，则对该 `k` 输出 `−1`。

## 输入格式

- 第一行：一个整数 `T`（`1 ≤ T ≤ 250000`），测试组数。
- 每组测试用例五行：
  1. 一个偶数 `n`（`2 ≤ n ≤ 5×10⁵`）；
  2. 正则括号序列 `S`（只含 `(` 与 `)`）；
  3. 正则括号序列 `T`；
  4. `n` 个整数 `a₁,…,aₙ`（`1 ≤ a_i ≤ 10⁹`）；
  5. `n` 个整数 `b₁,…,bₙ`（`1 ≤ b_i ≤ 10⁹`）。

保证所有测试用例的 `n` 之和不超过 `5×10⁵`。

## 输出格式

每组测试用例输出一行 `n+1` 个整数（空格分隔）：第 `k+1` 个整数（`0 ≤ k ≤ n`）为恰好选 `k` 个位置替换后的最大可能权重；若该 `k` 无解则输出 `−1`。

### 样例解释（用例 1）
