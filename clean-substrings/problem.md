# E. Clean Substrings

**来源**：[Codeforces Round 1123 (Div. 2) — Problem E](https://codeforces.com/contest/2267/problem/E)

- 时间限制：2 秒
- 内存限制：256 MB
- 题目标签：combinatorics / data structures / math

## 题目描述

一个长度为 $m$ 的二进制串 $t$ 被称为 **clean**，如果对所有 $1 \le i < m$ 都有 $t_i = t_{i+1}$（即全串全 $0$ 或全 $1$）。

智能机器人可以对任意二进制串 $t$ 执行一次操作（花费 $1$ 枚硬币）：

- 任选 $t$ 的一个 **clean 子串**；
- 把该子串全部取反（$0$ 变 $1$，$1$ 变 $0$）。

定义：

- $beauty(t)$：把 $t$ 变成 clean 所需的最少硬币数；
- $power(t)$：$t$ 的**所有子串**的 beauty 之和。

给定长度为 $n$ 的二进制串 $s$。共 $q$ 次修改，每次把 $s_i$ 取反。要求输出修改前以及每次修改后的 $power(s)$。

## 输入格式

第一行测试数 $t$（$1 \le t \le 10^4$）。每组数据：

- 第一行 $n, q$（$1 \le n, q \le 2\times10^5$）；
- 第二行二进制串 $s$；
- 接下来 $q$ 行，每行一个整数 $i$（$1 \le i \le n$）——翻转位置 $i$。

保证 $\sum n \le 2\times10^5$、$\sum q \le 2\times10^5$。

## 输出格式

每组测试输出 $q+1$ 个整数（空格分隔）：修改前的答案以及每次修改后的答案。

## 样例

### 输入

```
4
3 1
110
2
4 2
1010
1
2
8 4
10101110
3
5
2
3
10 5
1100101110
1
6
10
7
3
```

### 输出

```
2 2
7 5 5
36 23 22 25 26
61 66 41 35 59 60
```

### 样例解释（第一组）

$s = 110$，power = 2：

- 长度 1 子串 beauty 全为 0；
- `11` beauty = 0；`10`（位置 2-3）beauty = 1；`110` beauty = 1。

翻转位置 2 → `100`，power 仍为 2（断点从右段挪到左段，总和不变）。
