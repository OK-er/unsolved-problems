# Come Be My Friend (D2 Hard) 解题思路

**题目**：[2261D2 — Codeforces Round 1128](https://codeforces.com/contest/2261/problem/D2)
**题解**：[官方 Editorial](https://codeforces.me/blog/omsincoconut)

已有 m 个区间检测器，加最少新区间使得每个位置签名唯一。

---

## 一、XOR 哈希计算签名

每个位置 $i$ 的签名 = 覆盖它的检测器集合。

用 XOR 哈希：第 $j$ 个检测器随机一个 64 位数 $r_j$，区间 $[l, r]$ 对差分数组：
$$d_l \mathrel{\oplus}= r_j, \quad d_{r+1} \mathrel{\oplus}= r_j$$

前缀异或得到 $h_i = d_1 \oplus d_2 \oplus \cdots \oplus d_i$。$h_i$ 就是位置 $i$ 的签名哈希。冲突概率极低。

## 二、等价类与 nxt 数组

对每个位置 $i$，定义 $nxt_i$ = 最小的 $j > i$ 使得 $h_j = h_i$。

如果 $h_i = h_j$（同签名），必须有某个新区间的端点落在 $(i, j)$ 之间。

对每个 $i$，只需要考虑 $nxt_i$（最近的相同签名位置），因为相邻相同位置被分开后，不相邻的自然也分开。

## 三、区间嵌套性质

区间 $(i, nxt_i)$ 之间**要么嵌套，要么不相交，不可能交叉**。

**证明**：假设 $i < j < nxt_i < nxt_j$。因为 $nxt_i$ 是 $i$ 之后第一个相同签名的位置，所以 $h_i \ne h_j$，存在某个检测器恰好覆盖 $i, nxt_i$ 但不覆盖 $j$（或反之），与区间连续性矛盾。

## 四、叶子区间

去掉"包含其他区间"的区间，剩下的是**叶子区间**（最内层，两两不相交）。

设叶子区间数为 $q$。每个叶子区间内必须放一个新端点。

## 五、构造端点

在每个叶子区间 $(L, R)$ 内放端点 $b = R - 1$（位置 $R-1$ 和 $R$ 之间）。

排序得到 $b_1 < b_2 < \cdots < b_q$。

### 端点补全

- 若 $q$ 为奇数：在位置 1 前补一个端点 $b = 0$，使总数为偶数；
- 若 $q$ 为偶数：检查 $h_1$ 和 $h_n$（首末区域签名）是否相同；
  - 若相同：在位置 1 前（$b=0$）和位置 $n$ 后（$b=n$）各补一个端点；
  - 若不同：不补。

最终端点 $c_1 < c_2 < \cdots < c_{2k}$，$k$ = 新增检测器数。

## 六、安装检测器

对每个 $1 \le i \le k$，安装区间：
$$[c_i + 1,\ c_{i+k}]$$

前 $k$ 个端点依次开启检测器，后 $k$ 个端点依次关闭。

## 七、答案公式

$$
k =
\begin{cases}
0, & q = 0 \\
\lceil q/2 \rceil, & q \text{ 奇数} \\
q/2, & q \text{ 偶数且 } h_1 \ne h_n \\
q/2 + 1, & q \text{ 偶数且 } h_1 = h_n
\end{cases}
$$

## 八、复杂度

$O(n + m)$ 期望时间（哈希 + 单扫描）。

---

## 九、样例验证

| 样例 | q | h₁=hₙ? | k | 输出 |
|---|---|---|---|---|
| n=1, m=0 | 0 | - | 0 | 0 ✓ |
| n=2, m=0 | 1 | - | 1 | 1 ✓ |
| n=3, m=0 | 2 | 是 | 2 | 2 ✓ |
| n=5, [2,2],[4,4] | 2 | 是 | 2 | 2 ✓ |
| n=8, 7个滑动区间 | 0 | - | 0 | 0 ✓ |
| n=5, [2,3],[1,5] | 2 | 是 | 2 | 2 ✓ |
| n=4, [1,2],[3,4] | 2 | 否 | 1 | 1 ✓ |
