# 构造问题（D）

**来源**：题面截图（与[洛谷 P3599 Koishi Loves Construction](https://www.luogu.com.cn/problem/P3599) Task1 同题）
**限制**：1 秒，512 MB

## 题目描述

对于长度为 $n$ 的排列 $p$，记前缀和 $S_i = \sum_{j=1}^{i} p_j$。若对任意 $1 \le i < j \le n$，$S_i$ 与 $S_j$ 对 $n$ 取模的余数互不相同，则称 $p$ 是"丰富"排列。

给定 $n$，构造一个长度为 $n$ 的"丰富"排列。无解输出 $-1$。

## 输入格式

一行一个整数 $n$（$2 \le n \le 2 \times 10^5$）。

## 输出格式

一行 $n$ 个整数 $p_i$，或 $-1$。

## 样例

输入：
```
3
```
输出：
```
-1
```

输入：
```
4
```
输出：
```
4 3 2 1
```
（注：答案不唯一，$[4,1,2,3]$ 也合法）

$S_1=4, S_2=7, S_3=9, S_4=10$，对 4 取模分别为 $0,3,1,2$，互不相同。
