# 构造问题（D）解题思路

## 一、无解判定

$S_1, \ldots, S_n$ 共 $n$ 个值 mod $n$ 互不相同，恰好是 $0, 1, \ldots, n-1$ 的排列。

**关键观察**：数 $n$ 必须放在第一位。

**证明**：若 $n$ 不出现在第一位，设 $p_k = n$（$k \ge 2$），则 $S_k \equiv S_{k-1} \pmod n$，矛盾。故 $p_1 = n$，即 $S_1 \equiv 0 \pmod n$。

又 $S_n = n(n+1)/2$：
- $n$ 奇数时 $S_n \equiv 0 \pmod n$，与 $S_1 \equiv 0$ 重复，**无解**；
- $n$ 偶数时 $S_n \equiv n/2 \pmod n \ne 0$，可能有解。

## 二、构造（n 偶数）

让前缀和 mod $n$ 按以下顺序排列：
$$S_1 \equiv 0,\ S_2 \equiv 1,\ S_3 \equiv n-1,\ S_4 \equiv 2,\ S_5 \equiv n-2,\ \ldots$$

相邻两项之差 $p_i = S_i - S_{i-1}$（整数），得到排列：

$$p = [n,\ 1,\ n-2,\ 3,\ n-4,\ 5,\ \ldots]$$

即：
- $p_1 = n$；
- $i$ 偶数：$p_i = i - 1$；
- $i$ 奇数（$i \ge 3$）：$p_i = n - (i - 1)$。

## 三、验证

$S_i \bmod n$ 依次为 $0, 1, n-1, 2, n-2, \ldots, n/2$，恰好遍历所有余数，无重复。

## 四、复杂度

$O(n)$ 构造，$O(n)$ 输出。

## 五、样例

$n=4$：$p = [4, 1, 2, 3]$。
$S = [4, 5, 7, 10]$，mod 4 = $[0, 1, 3, 2]$，合法。

$n=6$：$p = [6, 1, 4, 3, 2, 5]$。
$S = [6, 7, 11, 14, 16, 21]$，mod 6 = $[0, 1, 5, 2, 4, 3]$，合法。
