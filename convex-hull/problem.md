# P17518 [ECUSTPC 2026 Fall] 凸包

**来源**：[洛谷 P17518](https://www.luogu.com.cn/problem/P17518)（华东理工大学 2026 秋季校赛）

## 题目描述

给定 $n$ 个一元二次不等式，每个形式为：

$$a_i x^2 + b_i x + c_i > 0$$

对任意 $1 \le i \le n$，保证 $a_i < 0$（开口向下）。

判断是否存在**整数** $x$，使得这 $n$ 个不等式同时成立。

## 输入格式

第一行测试数 $T$（$1 \le T \le 10^4$）。每组数据：

- 第一行 $n$（$1 \le n \le 2\times10^5$）；
- 接下来 $n$ 行每行三个整数 $a_i, b_i, c_i$（$-10^5 \le a_i \le -1$，$-10^5 \le b_i, c_i \le 10^5$）。

保证 $\sum n \le 2\times10^5$。

## 输出格式

每组数据输出 `YES` 或 `NO`（大小写不敏感）。

## 样例

### 输入

```
5
2
-1 0 4
-1 4 -3
3
-1 100000 0
-1 202 10000
-2 400 19998
2
-1 2 0
-1 0 -1
2
-100000 0 100000
-1 0 4
2
-1 2 0
-1 4 -3
```

### 输出

```
NO
YES
NO
YES
NO
```

### 样例解释

第 4 组：$-100000x^2 + 100000 > 0 \Rightarrow -1 < x < 1$；$-x^2 + 4 > 0 \Rightarrow -2 < x < 2$。交集 $(-1, 1)$ 含整数 $x=0$，输出 `YES`。

第 1 组：$(-2, 2)$ 与 $(1, 3)$ 交集为 $(1, 2)$，开区间内无整数，输出 `NO`。
