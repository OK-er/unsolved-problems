# 删除连通点集（Delete Connected Set）

## 题目描述

给定一棵 `n` 个节点的树，每个节点被染成 `R` 或 `B` 两种颜色之一。

你必须**删除一个非空连通点集 `S`**（即被删除的节点在原树上互相连通），使得删除后剩余图里**每一个连通块内部的节点颜色全部相同**。

求 `S` 的最小可能大小。

## 输入格式

- 第一行：一个整数 `n`，以及一个长度为 `n` 的字符串 `s`，`s[i]` 表示第 `i` 个节点的颜色（`R` 或 `B`）。
- 接下来 `n-1` 行：每行两个整数 `u, v`，表示树的一条边。

## 输出格式

- 一个整数，表示最小删除的节点数量。

## 数据范围

- `1 ≤ n ≤ 2 × 10^5`

## 样例

### 样例 1

输入：

```
5 RBRBR
1 2
2 3
3 4
4 5
```

输出：

```
3
```

解释：树是一条链 `R - B - R - B - R`。删除连通点集 `S = {2, 3, 4}`，剩余节点 `1`（R）和 `5`（R）各自构成单色连通块，满足条件。可以证明不存在大小小于 3 的合法删除方案。
