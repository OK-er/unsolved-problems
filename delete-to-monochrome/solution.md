# 删除连通点集 · 解题思路

## 一句话思路

**最大化保留的节点数**，答案 = `n - 最大保留数`。用一次树形 DP 求出最大保留数，O(n)。

## 核心观察

删掉连通集合 S 后，剩余部分是若干**单色连通块**。

关键性质：所有被保留的单色连通块，在树上必然"夹"在某一条被删除的路径两端。等价地说：

> 一定存在一条边，把树切成两侧：
> - 一侧包含**全部 R**（或全部 B），这侧内部可以处理成若干单色保留块；
> - 另一侧**完全没有 R**（或完全没有 B），天然就是单色的，可以整侧保留。

枚举这条"分界边"即可覆盖所有最优方案。

### 为什么成立

删除的 S 是连通集合。剩余的所有单色块都被 S 隔开。
- 若剩余只有一个单色块：把它所在子树与外部切开，外部（可能为空）也天然单色。
- 若剩余两个及以上单色块：它们在树上被 S 依次隔开，取最外侧两个块，它们之间的路径属于 S。沿这条路径上某条边切开，两侧分别只含一种颜色的保留块。

因此，只要枚举每个子树 u，判断"u 子树是否包含全部 R 或全部 B"，就能枚举到所有合法割法。

## DP 定义

设：

- `C0[u]`：u 子树中 R 的个数
- `C1[u]`：u 子树中 B 的个数
- `cnt[u]`：u 子树节点总数
- `s0 / s1`：整棵树 R / B 的总数

`dfs(u)` 返回：**在 u 子树内部，把"需要删掉的内部连通路径"删掉之后，剩余单色块能保留的节点总数**（子树内部的保留量，不含外部）。

转移：

```
sum = Σ dfs(v)              // 每个孩子子树内部先处理
if C0[u] == 0 或 C1[u] == 0:
    sum++                    // 当前整棵子树单色，整块保留（向上提供 1 块）
```

更新答案（关键一步）：

```
if C0[u] == s0 或 C1[u] == s1:
    // u 子树包含了全部某一种颜色
    // 则 u 子树之外的部分全部是另一种颜色，天然单色，全部保留
    total_save = (n - cnt[u]) + sum
    ans = max(ans, total_save)
```

- `n - cnt[u]`：u 子树外的节点全部保留（它们只有一种颜色）。
- `sum`：u 子树内部处理后能保留的节点数。
- 两者相加即"以 u 子树为一侧"的最优保留总数。

最终答案：`ans = n - 最大保留数`。

## 样例验证

## 一句话思路

**最大化保留的节点数**，答案 = `n - 最大保留数`。一次树形 DP 即可求出最大保留数，O(n)。

## 核心观察

删掉连通集合 S 后，剩余部分是若干**单色连通块**。

关键性质：**一定存在一条"分界边"**，把树切成两侧，使得：

- 一侧子树包含**全部 R**（或全部 B）；
- 另一侧完全没有这种颜色，天然单色，可以整侧保留。

枚举这条分界边（即枚举每个子树 u），就能覆盖所有最优方案。

### 为什么成立

S 是连通集合，所有保留的单色块都被 S 隔开：

- 若剩余只有一个单色块：把该块所在子树与外部切开即可；
- 若剩余多个单色块：取最外侧两个保留块，它们之间的路径都属于 S，沿路径上某条边切开，两侧分别只含单色保留块。

因此"枚举子树 u 是否包含全部 R / 全部 B"即可枚举到所有合法割法。

## DP 定义

- `C0[u]`：u 子树中 R 的个数
- `C1[u]`：u 子树中 B 的个数
- `cnt[u]`：u 子树节点总数
- `s0 / s1`：整棵树 R / B 的总数

`dfs(u)` 返回：**u 子树内部删除必要连通路径后，剩余单色块能保留的节点总数**。

转移（自底向上）：

```
sum = Σ dfs(v)                // 先处理每个孩子子树内部
if C0[u] == 0 或 C1[u] == 0:
    sum++                      // 当前整棵子树单色，整块保留
```

更新答案（关键一步）：

```
if C0[u] == s0 或 C1[u] == s1:
    // u 子树包含全部某一种颜色
    // 则 u 子树之外的部分全部是另一种颜色，天然单色，整侧保留
    total_save = (n - cnt[u]) + sum
    ans = max(ans, total_save)
```

- `n - cnt[u]`：u 子树外全部保留（只有一种颜色）
- `sum`：u 子树内部处理后可保留的节点数
- 两者相加 = 以 u 子树为一侧的最优保留总数

最终答案：`n - ans`。

## 样例验证

样例：`n=5`，`s=RBRBR`，链 `1-2-3-4-5`，`s0=3, s1=2`。

DFS 自底向上（以 1 为根）：

| 节点 | 子树范围 | C0 | C1 | sum(返回) | 更新 |
|---|---|---|---|---|---|
| 5 | {5} | 1 | 0 | 1（单色++） | - |
| 4 | {4,5} | 1 | 1 | 1 | - |
| 3 | {3,4,5} | 2 | 1 | 1 | - |
| 2 | {2,3,4,5} | 2 | 2 | 1 | `C1==s1`：total_save = (5-4)+1 = 2 → ans=2 |
| 1 | {1..5} | 3 | 2 | 2（单色++） | `C0==s0`：total_save = 0+1 = 1，不更新 |

`ans = 2`，答案 = `5 - 2 = 3` ✓

解释：节点 2 的子树包含全部 B（C1=2=s1），外部只有节点 1（R），内部可保留的单色块为节点 5（R），共保留 2 个；删除 `{2,3,4}` 正好 3 个。

## 复杂度

- 时间：O(n)，单遍 DFS。
- 空间：O(n)。

## 常见误区

- 不要枚举所有连通子集（指数级）。
- 不要把问题想成"只保留一个单色块"——最优解可能是保留**两个同色块**（如样例保留节点 1 和 5）。
- 答案要开 `long long`（n 最大 2×10^5，但保险起见）。
