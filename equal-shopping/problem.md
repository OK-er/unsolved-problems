# D - Equal Shopping

- 来源：[AtCoder Weekday Contest 0163 Beta](https://atcoder.jp/contests/awc0163/tasks/awc0163_d)（2026-09-23，配点 400）
- 时间限制：2 秒 / 内存限制：1024 MiB

## 题目描述

Takahashi 和 Aoki 去购买纪念品。共有 `N` 家店（编号 `1..N`），在第 `i` 家店可以购买 `L_i` 到 `R_i`（含）之间的任意整数金额的商品。

**购物计划** 为每家店指定恰好一种状态：

- 无人购物；
- 仅 Takahashi 购物，并在该店允许范围内选择一个整数金额；
- 仅 Aoki 购物，并在该店允许范围内选择一个整数金额。

即，两人不能在同一家店同时购物。

**均等购物计划**：满足以下全部条件：

- Takahashi 恰好去 `P` 家店；
- Aoki 恰好去 `Q` 家店；
- Takahashi 的总购买金额等于 Aoki 的总购买金额。

两个购物计划**不同**，当且仅当存在至少一家店满足：该店状态不同；或同一人在该店选择的金额不同。

接下来依次进行 `M` 次价格范围修改。第 `j` 次修改把店 `X_j` 的允许购买金额范围替换为 `[A_j, B_j]`。修改是**累积**的（保留此前修改的结果，在其基础上再应用新修改）。

求每次修改后均等购物计划的数量，对 `998244353` 取模。

## 输入格式

```
N P Q M
L_1 R_1
L_2 R_2
...
L_N R_N
X_1 A_1 B_1
X_2 A_2 B_2
...
X_M A_M B_M
```

## 输出格式

输出 `M` 行，第 `j` 行为第 `j` 次修改后均等购物计划数模 `998244353`。

## 约束

- `1 ≤ N ≤ 2000`
- `1 ≤ P ≤ 3`，`1 ≤ Q ≤ 3`，`P + Q ≤ N`
- `1 ≤ M ≤ 1000`
- `N × M ≤ 2000`
- `1 ≤ L_i ≤ R_i ≤ 20`
- `1 ≤ X_j ≤ N`，`1 ≤ A_j ≤ B_j ≤ 20`
