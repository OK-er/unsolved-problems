# P17517 [ECUSTPC 2026 Fall] 根除

**来源**：[洛谷 P17517](https://www.luogu.com.cn/problem/P17517)（华东理工大学 2026 秋季校赛）

## 题目描述

定义数论函数 $f(n) = \min\{a \mid n = a b^2,\; a,b \in \mathbb{N}\}$，即把 $n$ 中所有平方因子提走后剩下的**平方自由部分**（如 $\sqrt{432} = 12\sqrt3$，$f(432) = 3$）。

给定 $q$ 次询问，每次给定 $l, r$，求 $\sum_{i=l}^r f(i) \pmod{998244353}$。

## 输入格式

第一行 $q$（$1 \le q \le 500$）。接下来 $q$ 行每行两个整数 $l, r$（$1 \le l \le r \le 10^{12}$）。

## 输出格式

每次询问输出一行答案。

## 样例

### 输入

```
4
432 432
1 10
10 15
1 100000000
```

### 输出

```
3
38
66
651260790
```

### 样例解释

$f(1..15) = 1,2,3,1,5,6,7,2,1,10,11,3,13,14,15$。

$\sum_{10}^{15} f(i) = 10+11+3+13+14+15 = 66$。
