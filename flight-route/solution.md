# P4568 [JLOI2011] 飞行路线 · 解题思路

## 一句话思路

**把"免费次数"作为 DP 的第二个维度**：`dist[v][used]` 表示从 `s` 到 `v`、已经免费使用了 `used` 条航线的最少花费。每条边有两种走法——付费（花费 `c`）或免费（花费 `0`，`used+1`），用 Dijkstra 在 `n × (k+1)` 个状态上跑最短路。

## 一、状态设计与转移

状态：`dist[v][used]`，其中 `used ∈ [0, k]`。

对边 `(v, to, c)`：

```
付费：dist[to][used]   <- min(dist[to][used],   dist[v][used] + c)   (used 不变)
免费：dist[to][used+1] <- min(dist[to][used+1], dist[v][used] + 0)   (used < k)
```

- 每个状态 `(v, used)` 是一个"分层图"节点：`used` 相同构成原图的一层，`used` 增 1 表示免费穿过一条边到下一层；
- 免费次数可以少于 `k`（不是必须用完），所以答案取 `min over used ∈ [0,k] dist[t][used]`。

## 二、正确性

- Dijkstra 在 `n(k+1)` 个节点、`O(m(k+1))` 条边的图上跑，堆优化的正确性不依赖具体图的形态；
- 每条航线最多免费一次：因为状态维度 `used` 严格递增且上限 `k`，不会重复免费同一条边；
- 免费与付费两条转移互斥、覆盖全部情况：任意一条可行路径都可以按"哪些边免费"唯一映射到一条状态路径。

## 三、复杂度

- 状态数：`n × (k+1) ≤ 10⁴ × 11 ≈ 1.1×10⁵`
- 转移数：`m × (k+1) × 2 ≈ 5×10⁴ × 11 × 2 ≈ 1.1×10⁶`
- 时间：`O(m·k·log(n·k))`，空间：`O(n·k + m)`，完全可行。

## 四、验证

- 官方样例：输出 `8`（`0→2` 直达免费，`2→3 + 3→4` 付费）；
- 构造用例：`k=0` 退化为普通最短路、`k≥1` 时免费直达边结果为 0 等，均符合预期；
- 150 组随机小图（`n ≤ 6`）与"枚举免费边子集 + 普通 Dijkstra"暴力对拍，无一错误。

## 常见误区

- **认为免费次数必须用完**：答案要对所有 `used` 取 min，不是只看 `dist[t][k]`；
- **忘记 `k=0`**：免费转移被 `used < k` 挡住，程序自然退化为普通 Dijkstra；
- **同一条边重复免费**：状态维度保证 `used` 只增不减，不会在同一层内反复使用免费额度；
- **数据规模**：直接开 `n×k` 的 dist 二维数组（约 1.1×10⁵ 个 int）即可，不需要显式建 k+1 层图。
