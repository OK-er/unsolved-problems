# Jewel Necklace（宝石项链 · GCD）

- 来源：AtCoder 风格题面（题号未在题面图中显示，暂按内容命名）
- 约束：`2 ≤ N ≤ 10^6`，`1 ≤ A_i ≤ 10^6`

## 题目描述

Takahashi 有 `N` 颗宝石，宝石编号为 `1..N`，第 `i` 颗宝石的品质值为 `A_i`。

他要从中选择 **至少 2 颗** 宝石制作项链。项链的"美观度"定义为所选宝石品质值的 **最大公约数（GCD）**（美观度只取决于所选宝石的集合，与排列无关）。

Takahashi 首先希望 **最大化美观度**；若达到最大美观度的选法有多种，他希望 **选择宝石数最少** 的那一种（剩下的宝石可另作他用）。

更精确地，考虑集合 `{1,2,…,N}` 的 **至少包含 2 个元素** 的子集，定义 `G` 与 `K`：

- 对所有这样的子集 `S`，考虑 `gcd(A_i | i ∈ S)`，记 `G` 为这个 GCD 的 **最大值**；
- 在所有 `gcd(S) = G` 的子集中，记 `K` 为元素个数的最小值。

求项链未使用的宝石数，即 `N − K`。

## 输入格式

```
N
A_1 A_2 ... A_N
```

- 第一行：整数 `N`（宝石数量）；
- 第二行：`N` 个整数 `A_i`，空格分隔。

## 输出格式

输出一行一个整数 `N − K`。

## 样例

### 样例 1

输入：

```
4
6 10 15 21
```

输出：

```
2
```

解释：任意两两 GCD 中最大的是 `gcd(10,15)=5`，达到 `5` 最少只需 `{10,15}` 两颗宝石，`K=2`，输出 `4-2=2`。

### 样例 2

输入：

```
5
7 11 13 17 19
```

输出：

```
3
```

解释：任意两颗 GCD 均为 `1`，`G=1`，选任意两颗即达到，`K=2`，输出 `5-2=3`。
