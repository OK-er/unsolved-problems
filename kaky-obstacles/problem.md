# Kaky 撞障碍物（Kaky Obstacles）

- 来源：题面截图（来源未显示）
- 题面未提供官方样例（下附自测构造样例）

## 题目描述

Kaky 在一个无限大的方格平面中，初始时他的坐标为 `(0,0)`。在这个平面中共有 `k` 个障碍物。

接下来，他会按指令行动 `n` 次，用一个字符串 `s = s₁s₂…sₙ` 表示，具体规则：

- 若 `sᵢ = U`，向上移动：`(x,y) → (x−1,y)`
- 若 `sᵢ = D`，向下移动：`(x,y) → (x+1,y)`
- 若 `sᵢ = L`，向左移动：`(x,y) → (x,y−1)`
- 若 `sᵢ = R`，向右移动：`(x,y) → (x,y+1)`
- 若 `sᵢ = N`，可以**自由选择**向上、下、左、右移动一步，**或原地不动**

问：是否存在一种移动方式会让他**撞到障碍物**（即某次移动后到达障碍物所在坐标）？

## 输入格式

每个测试文件包含多组测试数据。第一行一个整数 `T (1 ≤ T ≤ 10³)` 表示数据组数。

每组数据：

- 第一行两个正整数 `n, k (1 ≤ n, k ≤ 5000)`；
- 第二行一个长度为 `n` 的字符串 `s`，保证 `sᵢ ∈ {U,D,L,R,N}`；
- 之后 `k` 行，第 `i` 行两个整数 `xᵢ, yᵢ (−5000 ≤ xᵢ, yᵢ ≤ 5000)`，为第 `i` 个障碍物的坐标。

保证障碍物坐标两两不同，且 `(0,0)` 处不存在障碍物。保证单个测试文件的 `n` 之和不超过 `5000`，`k` 之和不超过 `5000`。

## 输出格式

每组数据输出一行。若存在一种移动方式撞到障碍物，输出 `Yes`，否则输出 `No`。大小写不限。
