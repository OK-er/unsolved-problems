# Kaky 撞障碍物 · 解题思路

## 一句话思路

把指令分成"确定部分"与"弹性部分"：`U/D/L/R` 产生确定位移，`N` 提供**自由调节量**。对每个前缀 `i`，障碍物 `(X,Y)` 撞上，当且仅当：

```
|X - dx[i]| + |Y - dy[i]| ≤ cn[i]
```

其中 `dx[i], dy[i]` 是前 `i` 步中确定指令的累计位移，`cn[i]` 是前 `i` 步中 `N` 的数量。

## 一、前缀状态分解

对第 `i` 步结束后的位置，分两部分看：

1. **确定部分**：`U/D/L/R` 的位移固定，累计为 `(dx[i], dy[i])`；
2. **弹性部分**：前缀中 `cn[i]` 个 `N` 步，每步可选上/下/左/右/原地。

设 N 步累计产生的额外位移为 `(a,b)`。**可达集合**为：

```
S(c) = { (a,b) : |a| + |b| ≤ c }
```

### 证明

- 每个 `N` 步要么不动（曼哈顿贡献 0），要么移动一格（贡献 1）；
- 所以 `c` 步后曼哈顿距离最多为 `c`（`|a|+|b| ≤ c`）；
- 反过来，任意 `(a,b)` 满足 `|a|+|b| ≤ c` 都可实现：先走 `|a|+|b|` 步到达，多余的 `c − |a|−|b|` 步**原地不动**即可。

**关键点**：因为可以原地不动，**不存在奇偶性约束**（不需要像"只能上下左右移动"那样配对往返），这是本题最容易想错的地方。

## 二、撞上障碍物的判定

第 `i` 步结束后位置可达集合 = `(dx[i], dy[i]) + S(cn[i])`。

所以 `(X,Y)` 能被撞上，当且仅当存在前缀 `i` 使：

```
|X - dx[i]| + |Y - dy[i]| ≤ cn[i]
```

由于初始 `(0,0)` 无障，且每步结束后位置即为"尝试进入"的坐标，只需检查全部 `n` 个前缀位置即可（`N` 原地不动不改变位置，若此前已撞上则早已判定 Yes）。

## 三、复杂度

- 预处理前缀：`O(n)`；
- 判定：对每个障碍物枚举全部前缀，`O(k·n)`；
- 总复杂度：`Σ n·k ≤ (Σ n)·(Σ k) ≤ 5000 × 5000 = 2.5×10⁷`（每组数据上限），C++ 轻松通过。

## 四、验证

- 8 组构造测试全部符合预期（含 N 步可达边界、奇偶陷阱、原地不动等场景）；
- 200 组随机数据（n ≤ 5，暴力枚举每个 `N` 的全部 5 种选择）与程序对拍，无一错误。

## 常见误区

- **以为 N 有奇偶约束**：N 可以原地不动，多余步数直接原地即可，`|a|+|b| ≤ c` 就是充要条件，不需要 `≡ c (mod 2)`；
- **忽略 N 步原地**：`N` 不是"必须移动一格"，原地不动是它的合法选择，这让可达集合变成一个完整的曼哈顿圆盘；
- **方向定义**：本题按题面，`U` 使 `x` 减 1、`D` 使 `x` 加 1、`L` 使 `y` 减 1、`R` 使 `y` 加 1，与常见坐标约定不同，实现时严格按题面写。
