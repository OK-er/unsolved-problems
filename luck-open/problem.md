# 大运当头，开门红（F）

**来源**：某比赛 F 题（截图无比赛名）
**限制**：1 秒，512 MB

## 题目描述

给定长度为 $n$ 的卦牌序列，第 $i$ 张能量 $a_i$。

初始 $S = 0$，依次遍历每张卦牌，当前能量 $x$，$S$ 等概率变为 $S \mathbin{\text{OR}} x$ 或 $S \mathbin{\text{AND}} x$。

你可以在不改变相对顺序的前提下选出任意张牌进行测算。求最优选择下的最大好运值期望。

输出期望 $p/q$，以 $(p \times q^{-1}) \bmod 998244353$ 形式输出。

## 输入格式

- 第一行 $n$（$1 \le n \le 10^5$）；
- 第二行 $n$ 个整数 $a_i$（$1 \le a_i \le 10^9$）。

## 输出格式

一行一个整数，表示答案。

## 样例

输入：
```
3
10 4 6
```

输出：
```
499122182
```

最优选第 1、3 张（10 和 6），$S$ 可能为 14, 2, 6, 0，概率各 1/4，期望 $= 22/4 = 11/2$。
$11/2 \bmod 998244353 = 499122182$。
