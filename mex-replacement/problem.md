# F. MEX Replacement

**来源**：[Codeforces Round 1122 (Div. 3) — Problem F](https://codeforces.com/contest/2266/problem/F)

- 时间限制：2 秒
- 内存限制：256 MB
- 题目标签：binary search / brute force / greedy / implementation / math / sortings

## 题目描述

给定一个以压缩形式表示的非负整数多重集：每个值 $x_i$ 在多重集中出现 $y_i$ 次。

一次操作可以：

- 任选当前多重集中一个**非空子集**；
- 删除这些元素，向多重集中插入一个等于它们 MEX 的元素。

MEX：一组数 $c_1, c_2, \dots, c_k$ 的 MEX 是最小的、不在其中出现的非负整数。

操作可执行任意次（包括 0 次）。求过程中多重集里**可能出现的最大整数**。

## 输入格式

第一行测试数 $t$（$1 \le t \le 10^4$）。每组数据：

- 第一行 $n$（$1 \le n \le 2\times10^5$）——初始多重集中不同值的个数；
- 接下来 $n$ 行，每行两个整数 $x_i, y_i$（$0 \le x_i \le 10^9$，$1 \le y_i \le 10^9$），表示值 $x_i$ 出现 $y_i$ 次；
- $x_i$ 两两不同。

保证 $\sum n \le 2\times10^5$。

## 输出格式

每组数据输出一个整数——可出现的最大值。

### 样例解释

第一组初始多重集 $\{0,0,0,1,1,2,2,4\}$：

1. 取子集 $\{0,1,2\}$，它们的 MEX 是 $3$，替换后得到 $\{0,0,1,2,3,4\}$；
2. 再取 $\{0,1,2,3,4\}$，MEX 是 $5$，得到含 $5$ 的多重集。

更大的数无法出现，答案为 $5$。

第二组初始只有 $10$，它本身已是最大值，答案 $10$。
