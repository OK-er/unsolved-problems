# I Know About a Million Things 解题思路

**题目**：[2261C — Codeforces Round 1128](https://codeforces.com/contest/2261/problem/C)

删元素游戏：合法操作 = 删一个元素，或删一组和为偶数的元素。判断先手胜负。

---

## 一、状态抽象

设 $o$ = 奇数个数，$e$ = 偶数个数。

一次操作：
- **删一个元素**：$(o-1, e)$ 或 $(o, e-1)$，总是合法；
- **删一组和为偶数的元素**：删除的奇数个数必须是偶数（偶数不影响奇偶性），且总删除数 $\ge 2$。

目标：找出所有必败态（P-position）。

## 二、必败态推导

从 $(0,0)$ 开始倒推：

| 状态 $(o,e)$ | 可达状态 | 是否必败 |
|---|---|---|
| $(0,0)$ | 空，无法操作 | **必败** |
| $(1,0)$ | 删一奇 → $(0,0)$ | 胜 |
| $(0,1)$ | 删一偶 → $(0,0)$ | 胜 |
| $(1,1)$ | 删一奇 → $(0,1)$；删一偶 → $(1,0)$；删两元素和为奇不合法 | **必败** |
| $(2,0)$ | 删两奇（和偶）→ $(0,0)$ | 胜 |
| $(0,2)$ | 删两偶（和偶）→ $(0,0)$ | 胜 |
| $(3,0)$ | 删一奇 → $(2,0)$；删两奇 → $(1,0)$ | **必败** |
| $(0,3)$ | 删一偶 → $(0,2)$；删两偶 → $(0,1)$ | **必败** |

### 证明其余状态都是必胜态

- **$o$ 为偶数**：直接删所有元素（偶数个奇数，和为偶）→ $(0,0)$ 必败态，胜。
- **$o=1, e\ge 2$**：删 $e-1$ 个偶数（和偶）→ $(1,1)$ 必败态，胜。
- **$o=3, e\ge 1$**：删 $e$ 个偶数（和偶）→ $(3,0)$ 必败态，胜。
- **$o\ge 5$ 且为奇数**：
  - 若 $e\ge 1$：删 $o-1$ 个奇数（偶数个）+ $e-1$ 个偶数 → $(1,1)$ 必败态，胜；
  - 若 $e=0$：删 $o-3$ 个奇数（偶数个）→ $(3,0)$ 必败态，胜。
- **$e\ge 5$ 且为奇数（$o=0$）**：删 $e-3$ 个偶数 → $(0,3)$ 必败态，胜。

综上，必败态只有四个：

$$(0,0),\ (1,1),\ (3,0),\ (0,3)$$

实际输入 $n\ge 1$，所以只需判断后三个。

## 三、结论

后手胜（Larpity）当且仅当：

- $o=1$ 且 $e=1$（一奇一偶）；
- $o=3$ 且 $e=0$（三个奇数）；
- $o=0$ 且 $e=3$（三个偶数）。

否则先手胜（Moggity）。

---

## 四、复杂度

$O(n)$ per test，统计奇偶个数即可。

## 五、验证

官方样例：
- [7]：$o=1,e=0$ → Moggity ✓
- [2,3]：$o=1,e=1$ → Larpity ✓
- [1000000,999999,5,4,3,2]：$o=3,e=3$ → Moggity ✓
