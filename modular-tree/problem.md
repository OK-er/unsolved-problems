# G. Modular Tree

**来源**：[Codeforces Round 1122 (Div. 3) — Problem G](https://codeforces.com/contest/2266/problem/G)

- 时间限制：3 秒
- 内存限制：256 MB
- 题目标签：dfs and similar / dp / greedy / math / number theory / trees

## 题目描述

给定一棵以节点 $1$ 为根的有根树，共 $n$ 个节点。每个节点 $i$ 有初始值 $a_i$ 和模数 $b_i$，记当前值为 $x_i$（初始 $x_i = a_i$）。

可执行任意次操作：

- 选择节点 $u$，设 $s$ 为 $u$ 的所有直接子节点的当前值之和；
- 把 $x_u$ 更新为 $(x_u + s) \bmod b_u$。

求操作结束后所有节点值之和的最大值。

## 输入格式

第一行测试数 $t$（$1 \le t \le 10^4$）。每组数据：

- 第一行 $n$（$1 \le n \le 2\times10^5$）；
- 第二行 $n$ 个整数 $a_1, \dots, a_n$（$0 \le a_i < b_i$）；
- 第三行 $n$ 个整数 $b_1, \dots, b_n$（$1 \le b_i \le 10^9$）；
- 接下来 $n-1$ 行每行两个整数 $u, v$ 表示一条树边。

保证 $\sum n \le 2\times10^5$。

## 输出格式

每组数据输出一个整数——最大可能的节点值之和。

### 样例解释

第三组（$n=3$，链 $1-2-3$，$a=[0,2,3]$，$b=[7,3,4]$）：

对节点 1 操作三次：$[0,2,3] \to [2,2,3] \to [4,2,3] \to [6,2,3]$，总和 $6+2+3=11$。

第四组（$a=[0,0,1]$，$b=[5,2,2]$）：先操作节点 2 一次（$[0,0,1]\to[0,1,1]$），再操作节点 1 四次（$[0,1,1]\to\cdots\to[4,1,1]$），总和 $4+1+1=6$。
