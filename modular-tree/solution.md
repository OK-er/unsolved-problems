# Modular Tree 解题思路

**题目**：[G. Modular Tree — Codeforces Round 1122 (Div. 3)](https://codeforces.com/contest/2266/problem/G)

树上每个节点可加上"子节点当前值之和"再取模，求最大化总和。

---

## 一、关键结论：可达值是一个等差序列

对节点 $u$，设它所有直接子节点的当前值之和为 $s$。操作 $u$ 就是 $x_u \leftarrow (x_u + s) \bmod b_u$。

**核心观察**：节点 $u$ 的所有可达值形如

$$\{ (a_u + g_u \cdot x) \bmod b_u \mid x \in \mathbb{Z} \}$$

即从 $a_u$ 出发，以 $g_u$ 为步长、模 $b_u$ 的等差序列。其中 $g_u$ 是某个由子树决定的常数。

- **叶子节点**：没有子节点，$s=0$，操作不改变它的值 → $g_u = b_u$（步长等于模数，值固定为 $a_u$）。

## 二、g_u 的递推（叶子向上）

对内部节点 $u$，步长 $g_u$ 由三部分取 gcd 得到：

1. **子节点初始值之和 $S_u = \sum_{v \in son(u)} a_v$**：这是每次操作 $u$ 时加上的基准量；
2. **每个可变子节点的步长 $g_v$**：若子节点 $v$ 可变（$g_v < b_v$，即它的值能浮动），则它贡献的 $s$ 也能在 $g_v$ 的倍数范围内变化；
3. **模数 $b_u$**：模运算后步长受 $b_u$ 限制。

$$g_u = \gcd\bigl(b_u,\; S_u,\; \{g_v \mid v \in son(u),\; g_v < b_v\}\bigr)$$

不可变子节点（$g_v = b_v$）的值固定，不贡献浮动，故不计入 gcd。

## 三、求每个节点的最大值

可达值是 $a_u, a_u + g_u, a_u + 2g_u, \dots$（模 $b_u$）。不超过 $b_u - 1$ 的最大值为：

$$\max_u = a_u + \left\lfloor \frac{b_u - 1 - a_u}{g_u} \right\rfloor \cdot g_u$$

所有节点的最大值可以同时达到（先把某节点调到最大，再深入其子树内部调整而不影响它），故答案为 $\sum_u \max_u$。

---

## 四、复杂度

- 时间：$O(n \log b)$（一次 DFS，每层 gcd 为 $O(\log b)$）；
- 空间：$O(n)$。

## 五、验证

官方 8 组样例逐组匹配：

```
3 7 11 6 18 12 27 3999999996
```

## 六、易错点

1. **`gcd(0, x) = x`**：初始 gc 设 0，逐步 gcd 累积，空子节点集时 gc 最终 = gcd(0, b_u) = b_u（叶子正确）；
2. **可变子节点判定**：只有 $g_v < b_v$ 的子节点才贡献步长；叶子 $g_v = b_v$ 不可变；
3. **`childSum` 用初始值 $a_v$**：不是当前值——因为子树调整后子节点值虽然变了，但它们的浮动范围已由 $g_v$ 刻画，$S_u$ 的基准取初始值即可（gcd 性质保证）。
