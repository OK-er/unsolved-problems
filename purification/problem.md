# P17524 [ECUSTPC 2026 Fall] 净化行动 3

**来源**：[洛谷 P17524](https://www.luogu.com.cn/problem/P17524)（华东理工大学 2026 秋季校赛）

## 题目描述

平面上有 $n$ 个炮，固定在 $(x_1,y_1), \dots, (x_n,y_n)$。

炮的攻击规则（象棋规则）：若两个炮 $A$、$B$ 同行或同列，且它们之间**有且仅有**一个其他炮 $C$，则 $A$、$B$ 互相攻击（$C$ 为炮架）。

每次可选择一个**当前未被任何其他炮攻击**的炮摧毁，摧毁后立即移出棋盘。

问是否存在一种摧毁顺序能清空所有 $n$ 个炮。

## 输入格式

第一行测试数 $T$（$1 \le T \le 10^5$）。每组数据：

- 第一行 $n$（$1 \le n \le 2\times10^5$）；
- 接下来 $n$ 行每行两个整数 $x_i, y_i$（$-10^9 \le x_i, y_i \le 10^9$），位置两两不同。

保证 $\sum n \le 2\times10^5$。

## 输出格式

每组数据输出 `YES` 或 `NO`（大小写不敏感）。

## 样例

### 输入

```
3
3
0 0
0 1
0 2
4
0 0
1 0
2 0
3 0
8
2 0
0 1
1 1
2 1
1 2
2 2
3 2
1 3
```

### 输出

```
YES
NO
NO
```

### 样例解释

第 1 组：三炮同列，$(0,1)$ 未被攻击（它是炮架），先摧毁 $(0,1)$ 后其余两炮不再互相攻击，可依次摧毁。

第 2 组：四炮同行，$(0,0)$ 与 $(2,0)$ 互相攻击、$(1,0)$ 与 $(3,0)$ 互相攻击，全部被攻击，无炮可摧毁。
