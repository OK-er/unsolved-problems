# 净化行动 3 解题思路

**题目**：[P17524 [ECUSTPC 2026 Fall] 净化行动 3](https://www.luogu.com.cn/problem/P17524)

每次只能摧毁"当前未被任何炮攻击"的炮，问能否清空棋盘。

---

## 一、行/列内孤立判定

一个炮被攻击 ⟺ 它在所在行或所在列中，与另一个炮之间恰好隔一个炮。

单独看一行（或一列）有 $k$ 个炮，按坐标排序为 $p_1 < p_2 < \dots < p_k$，边为 $(p_i, p_{i+2})$：

- $k \le 2$：无三连续，所有炮在行内不被攻击（全孤立）；
- $k = 3$：仅中间炮 $p_2$ 是炮架，$p_1$ 与 $p_3$ 互相攻击 → **仅 $p_2$ 行内孤立**；
- $k \ge 4$：所有炮都在行内被攻击（无孤立）。

列内孤立判定完全同理。

**一个炮当前可被摧毁** ⟺ 它行内孤立 **且** 列内孤立（双孤立）。

## 二、BFS 模拟

删一个双孤立炮后，它所在行和列的炮数减少，结构变化可能产生新的双孤立炮（例如某行从 4 变 3，新的中间炮变孤立）。

用队列维护所有当前双孤立炮：

1. 初始对每个炮判定双孤立，入队；
2. 弹出一个双孤立炮删除，把它所在行、列重新扫描，将新的双孤立炮入队；
3. 重复直到队列空；
4. 删除数 == $n$ → `YES`，否则 `NO`。

每行/每列用 `set` 维护坐标排序后的炮，判定中间炮只需看它是否有左右邻居。

## 三、复杂度

- 每个炮被删一次，每次删除触发所在行/列的重新扫描；
- 总体 $O(n \log n)$（set 操作），$\sum n \le 2\times10^5$ 可过。

## 四、验证

官方 3 组样例：`YES NO NO` 逐组匹配。

## 五、易错点

1. **行和列都要判定**：只看行不看列会误判（某个炮行内孤立但列内被攻击）；
2. **删除后重新扫描整行/整列**：不能只更新邻居——行从 4 变 3 时新中间炮可能不是被删点的邻居；
3. **$k \ge 4$ 行/列无孤立炮**：一旦出现这种行/列，其中炮永远不能先被删，除非从其他方向改变结构（但行内结构不依赖列）。
