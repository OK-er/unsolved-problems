# P17521 [ECUSTPC 2026 Fall] 天外来物

**来源**：[洛谷 P17521](https://www.luogu.com.cn/problem/P17521)（华东理工大学 2026 秋季校赛）

## 题目描述

有 $n$ 颗水晶从左到右编号 $1 \sim n$，第 $i$ 颗初始含 $a_i$ 单位能量。按任意顺序依次采集全部水晶。

采集编号 $i$ 的水晶时：

- 获得该水晶当前所含能量，累加到总得分；
- 若 $i > 1$ 且 $i-1$ 还未采集，$i-1$ 的能量变成当前值的相反数；
- 若 $i < n$ 且 $i+1$ 还未采集，$i+1$ 的能量变成当前值的相反数。

求采集完所有水晶后的最大总得分。

## 输入格式

第一行测试数 $T$（$1 \le T \le 10^4$）。每组数据：

- 第一行 $n$（$1 \le n \le 2\times10^5$）；
- 第二行 $n$ 个整数 $a_1, \dots, a_n$（$-10^9 \le a_i \le 10^9$）。

保证 $\sum n \le 2\times10^5$。

## 输出格式

每组数据输出一个整数——最大总得分。

## 样例

### 输入

```
2
5
1 2 3 4 5
9
9 -9 8 -2 4 -4 3 -5 3
```

### 输出

```
15
47
```

### 样例解释

第 1 组：按 $3 \to 5 \to 1 \to 2 \to 4$ 顺序采集，总得分 $15$。
