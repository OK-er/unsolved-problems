# 天外来物 解题思路

**题目**：[P17521 [ECUSTPC 2026 Fall] 天外来物](https://www.luogu.com.cn/problem/P17521)

路径上按任意顺序采集，未采邻居取反，求最大总得分。

---

## 一、关键转化：边定向

每颗水晶 $i$ 最终被采集时，它的能量符号 = $(-1)^{k_i}$，其中 $k_i$ 是"比 $i$ 先采的邻居数"。

- 邻居 $j$ 若在 $i$ 之前被采，采集 $j$ 时 $i$ 未采 → $i$ 被取反一次；
- 故 $k_i$ 等于节点 $i$ 在路径图上的入度（把每条边从先采者指向后采者）。

路径图无环，**任意给每条边定向都对应一个合法的采集顺序**（取其拓扑序即可）。因此问题等价于：给每条边独立选向，最大化

$$\sum_{i=1}^n (-1)^{\text{indeg}(i)} \cdot a_i$$

## 二、入度与符号

- 节点 $1$：入度只取决于边 $(1,2)$ → 0 或 1；
- 节点 $n$：入度只取决于边 $(n-1,n)$ → 0 或 1；
- 内部节点 $i$：入度 = [左边邻居先采] + [右边邻居先采] ∈ {0, 1, 2}。

入度为偶 → $+a_i$；入度为奇 → $-a_i$。

## 三、DP（状态仅 2）

定义边 $i$（连接 $i$ 与 $i+1$）的方向 $d$：

- $d=0$：$i$ 先于 $i+1$；
- $d=1$：$i+1$ 先于 $i$。

`dp[d]`：处理完前 $i$ 个节点、边 $i$ 方向为 $d$ 时的最大得分。

结算节点 $i$（$2 \le i \le n-1$）时，已知前一条边方向 `prev` 与当前边方向 `d`：

| prev | d | 左边邻居先采 | 右边邻居先采 | 入度 | 贡献 |
|---|---|---|---|---|---|
| 0 | 0 | 是 | 否 | 1 | $-a_i$ |
| 1 | 0 | 否 | 否 | 0 | $+a_i$ |
| 0 | 1 | 是 | 是 | 2 | $+a_i$ |
| 1 | 1 | 否 | 是 | 1 | $-a_i$ |

转移：

$$\text{ndp}[0] = \max(\text{dp}[0]-a_i,\; \text{dp}[1]+a_i)$$
$$\text{ndp}[1] = \max(\text{dp}[0]+a_i,\; \text{dp}[1]-a_i)$$

- 初始化节点 1：`dp[0] = +a_1`（入度 0），`dp[1] = -a_1`（入度 1）；
- 终点节点 $n$（无右边邻居）：答案 = $\max(\text{dp}[0]-a_n,\; \text{dp}[1]+a_n)$。

---

## 四、复杂度

- 时间：$O(n)$；
- 空间：$O(1)$ 滚动数组。

## 五、验证

官方 2 组样例：`15`、`47` 逐组匹配。

## 六、易错点

1. **任意定向都合法**：路径无环，每条边方向独立，不需要担心环；
2. **入度奇偶决定符号**：入度 2 时符号为 $+$（取反两次）；
3. **首尾节点单独结算**：端点只有一条边，入度只能 0 或 1。

---

## 七、更优视角：反常顶点至多一个（数学证明）

手模样例可观察到：

- $a_i > 0$ 时，理想入度为**偶**（贡献 $+a_i$）；
- $a_i < 0$ 时，理想入度为**奇**（贡献 $-a_i = +|a_i|$）。

**理想入度**：正数偶、负数奇。**反常顶点** = 入度奇偶与理想不符的节点。

### 证明：反常顶点至多一个

设存在两个反常顶点 $i < j$。反转子路径 $i \to i+1 \to \dots \to j$ 上所有边的方向：

- 端点 $i, j$ 各翻转一条邻边 → 入度奇偶翻转 → 由反常变理想；
- 中间顶点 $k \in (i,j)$ 两条邻边同时反转 → 入度变化为 $0$ 或 $2$ → 奇偶不变 → 贡献不变。

总得分变化 $= 2|a_i| + 2|a_j| \ge 0$，与"当前已是最优"矛盾（若等号成立则修正后反常数更少）。**故反常顶点至多一个。**

### 贪心结论

- 所有数取绝对值求和 = $\sum |a_i|$，即"全部理想"时的得分；
- 反常顶点存在 ⟺ 正数个数为**偶数**（每个反常顶点翻转一个符号，奇偶性要求总数为偶）；
- 此时需贪心地让**绝对值最小**的数变成负数（代价最小），即从绝对值和中减去 $2 \cdot \min |a_i|$。

**最终公式**：

$$\text{ans} = \sum_{i=1}^n |a_i| - \begin{cases} 0, & \text{正数个数为奇} \\ 2 \cdot \min |a_i|, & \text{正数个数为偶} \end{cases}$$

验证样例 1：全正（正数 5 个，奇）→ $1+2+3+4+5 = 15$ ✓。
验证样例 2：正数 5 个（奇）→ $9+9+8+2+4+4+3+5+3 = 47$ ✓。

此视角比 DP 更直接，$O(n)$ 一次扫描即可，无需状态转移。
