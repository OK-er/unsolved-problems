# P17515 [ECUSTPC 2026 Fall] 一分为二 2

**来源**：[洛谷 P17515](https://www.luogu.com.cn/problem/P17515)（华东理工大学 2026 秋季校赛）

## 题目描述

给定长度为 $n$ 的数组 $a, b$。任选 $k \in [0, n]$，把 $a$ 的前 $k$ 个元素和 $b$ 的后 $n-k$ 个元素拼接成新数组 $c$。

从 $c$ 中选出恰好 $m$ 个**互不相邻**的元素，记其中最小的元素为 $p$，求 $p$ 的最大值。

## 输入格式

第一行测试数 $T$（$1 \le T \le 10^4$）。每组数据：

- 第一行 $n, m$（$1 \le m \le \lceil n/2\rceil \le n \le 2\times10^5$）；
- 第二行 $n$ 个整数 $a_i$（$-10^9 \le a_i \le 10^9$）；
- 第三行 $n$ 个整数 $b_i$（$-10^9 \le b_i \le 10^9$）。

保证 $\sum n \le 2\times10^5$。

## 输出格式

每组数据输出 $p$ 的最大值。

## 样例

### 输入

```
2
5 2
5 4 3 2 1
1 2 3 4 5
9 5
-1 1 -4 -5 -1 4 -1 -9 1
-9 -9 -8 2 4 -4 -3 -5 3
```

### 输出

```
5
-4
```

### 样例解释

第 1 组：$k=4$，$c=[5,4,3,2,5]$，选第 1、5 个元素（值均为 5），最小为 5。
