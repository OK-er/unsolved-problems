### 阶段一：组合计数地基（第 1 周）

---

**锚点 A1：排列组合基础与二项式定理**
- 所属领域：组合数学基础
- 前置锚点：无
- 【是什么】定义：`C(n,k)=n!/k!/(n-k)!`、`P(n,k)=n!/(n-k)!` 的定义与组合意义；`(1+x)^n=ΣC(n,k)x^k` 的二项式定理。能做什么：快速计算/化简含组合数的表达式。
- 【门槛·学习驱动点】最终公式里全是 `C(n,i)C(m,j)`，且加速第一步就要用 `C(n,i)C(i,l)=C(n,l)C(n-l,i-l)` 和 `(1+t)^{n-l}=ΣC(n-l,j)t^j`。不掌握组合数恒等变形，到 A6 拆分时会直接卡死，看不懂题解里任何一个等号。
- 【角色/作用】地基：整条路径唯一的元知识，所有后续锚点都建立在组合数的运算规则上。
- 【天花板·最低达标线】验收动作：不看资料，30 分钟内完成——① 手推 `C(n,i)C(i,l)=C(n,l)C(n-l,i-l)`；② 展开 `(1+x)^5`；③ 独立 AC 洛谷 P2822（组合数递推）。通过标准：推导无错、AC。
- 预估投入：2 天，每天 1.5h
- 训练动作：做题 + 手推恒等式
- 回退预案：卡住 >2 天 → 回退到"杨辉三角 + 具体小数字枚举"，换《具体数学》第 5 章开头
- 验收证据：（留空，训练时填）

**锚点 A2：映射计数（集合函数计数）**
- 所属领域：组合计数
- 前置锚点：A1
- 【是什么】定义：从大小为 i 的集合到大小为 j 的集合的**任意映射**共有 `j^i` 个；双射 `i!` 个；理解"选择集合 + 给每个元素分配目标"的两步计数法。能做什么：把图计数问题翻译成映射计数。
- 【门槛·学习驱动点】最终公式里的 `j^i·i^j` 就是"左非零点的出边各选一个右点 + 右非零点的出边各选一个左点"，这正是映射计数。不懂"为什么是 j^i 而不是 C(j,i) 或 j! "，就会在结构分析处卡住，得到错误公式（这是本题最常见的翻车点）。
- 【角色/作用】核心：连接"图结构"与"代数公式"的翻译器。
- 【天花板·最低达标线】验收动作：独立回答"每个点出度≤1 的有标号无向→有向图"系列计数：① n 个标号点、每个点出度恰为 1 的有向图数量 = n^n，能讲清理由；② 用"两步法"重述 `Σ_i C(n,i)j^i = (1+j)^n`。通过标准：讲解流畅、AC 两道映射计数小题（如 CF 计数 A/B）。
- 预估投入：2 天
- 训练动作：讲解 + 做题
- 回退预案：卡住 → 用小例子（n=2,j=2 手写全部 4 个映射）枚举感受
- 验收证据：（留空）

**锚点 A3：有向二分图与出度/零度**
- 所属领域：图论基础
- 前置锚点：A2
- 【是什么】定义：二分图（边只连接左-右）、有向边 L→R 与 R→L、出度/入度、零出度点。能做什么：分析"每个点出度≤1 + 不能走到零点"的图结构。

### 阶段二：组合恒等式与反演（第 2 周）

---

**锚点 A4：第二类 Stirling 数**
- 所属领域：组合数学（特殊数）
- 前置锚点：A1
- 【是什么】定义：`S(n,k)` = 把 n 个标号元素分成 k 个非空无标号集合的方案数；关键恒等式 `Σ_{t=0}^{k}(-1)^{k-t}C(k,t)t^i = k!·S(i,k)`。能做什么：把"幂"展开成"下降幂/组合数"的桥梁。
- 【门槛·学习驱动点】加速拆分的第一个恒等式就是它——没有它，`F_l(t)=ΣC(n,i)C(i,l)t^i` 无法反演回 `k!S(i,k)`，维度压缩无从谈起。
- 【角色/作用】核心工具：幂 ↔ 组合数转换的枢纽。
- 【天花板·最低达标线】验收动作：独立证明 `Σ_{t=0}^{k}(-1)^{k-t}C(k,t)t^i=k!S(i,k)`（用组合意义或生成函数），并用 i=3,k=2 手算验证。通过标准：证明成立、数值正确；可 AC 洛谷 P5395（第二类 Stirling 数·行，可只理解不 AC）。
- 预估投入：2 天
- 训练动作：独立证明 + 手算验证
- 回退预案：卡住 → 用集合划分组合意义直接数 S(i,k)，再反推恒等式
- 验收证据：（留空）

**锚点 A5：二项式反演**
- 所属领域：组合数学（反演）
- 前置锚点：A1
- 【是什么】定义：`a_k=Σ_t C(k,t)b_t ⟺ b_k=Σ_t (-1)^{k-t}C(k,t)a_t`；理解"恰好 ⟷ 至少"的计数转换。能做什么：把截断和/带符号和化简。
- 【门槛·学习驱动点】代码里 `X(k,l)=Σ_t (-1)^{k-t}C(k,t)F_l(t)` 就是一次标准的二项式反演。不学它，这段代码就是"魔法"，无法理解也无法迁移。

**锚点 A6：幂 ↔ Stirling 双向转换（含 Σ_k k!S(i,k)C(j,k)=j^i）**
- 所属领域：组合数学（综合）
- 前置锚点：A4、A5
- 【是什么】定义：`j^i=Σ_k k!S(i,k)C(j,k)`（即幂展开为组合数）；与前向恒等式合起来构成双向转换。能做什么：这是**最终合并公式的收尾步骤**——把 X(k,l)·Y(k,l) 的双重和还原成 `j^i·i^j`。

### 阶段三：模 2^64 数论（第 3 周）

---

**锚点 A7：模运算、逆元与模 2^64 的特殊性**
- 所属领域：数论
- 前置锚点：A1
- 【是什么】定义：模运算性质；`a^{-1}` 存在 ⟺ gcd(a,mod)=1；**模 2^64 下偶数无逆元**（2 不可逆），因此不能用"阶乘逆元"算组合数。能做什么：识别"哪些模数能用费马/逆元，哪些不能"。
- 【门槛·学习驱动点】本题取模是 2^64 而非质数——这直接否决了常规 `fac[n]*inv[m]*inv[n-m]` 的写法。不理解这一点，就会写出 WA 代码或卡在除法上。
- 【角色/作用】地基：阶段三的技术前提，解释"为什么必须用 2-adic"。
- 【天花板·最低达标线】验收动作：独立解释"为什么 2 在模 2^64 下没有逆元"，并说明"奇数一定有逆元、可用扩展欧几里得求"。通过标准：讲解清晰；可 AC 洛谷 P3811（质数模逆元，作为对照）。
- 预估投入：1 天
- 训练动作：讲解 + 做题
- 回退预案：卡住 → 先忘记 2^64，用 mod 质数练习逆元，再回来看偶数无逆元
- 验收证据：（留空）

**锚点 A8：Legendre / Kummer 定理（v2 与 popcount）**
- 所属领域：数论
- 前置锚点：A7
- 【是什么】定义：`v2(n!)=Σ⌊n/2^k⌋=n-popcount(n)`；`v2(C(n,m))=popcount(m)+popcount(n-m)-popcount(n)`（Kummer 定理）。能做什么：O(1) 得到组合数中因子 2 的个数。
- 【门槛·学习驱动点】2-adic 组合数的第一步就是算 2 的幂次 v，而代码里正是 `popcount(m)+popcount(n-m)-popcount(n)`。不学它，这段代码无法解释。
- 【角色/作用】核心：2-adic 计算的"指数部分"。
- 【天花板·最低达标线】验收动作：独立证明 v2(n!)=n-popcount(n)，并手算 v2(C(10,4)) 与代码公式核对一致。通过标准：数值一致、证明成立。
- 预估投入：1.5 天
- 训练动作：独立证明 + 手算核对
- 回退预案：卡住 → 从 v2(8!)、v2(10!) 具体枚举 2 的倍数/4 的倍数开始
- 验收证据：（留空）

**锚点 A9：2-adic 分解计算组合数（mod 2^64）**
- 所属领域：数论 × 组合数学
- 前置锚点：A8（+A7）
- 【是什么】定义：`C(n,m)=2^v·(奇数部分)`；预处理"去 2 因子后的奇数前缀积 di"及其逆元 id，`C=di[n]*id[m]*id[n-m]<<v`；v≥64 时结果为 0。能做什么：在模 2^64 下无除法规避除法。
- 【门槛·学习驱动点】这是本题代码里 `init()` 与 `C()` 两个函数的全部原理。不掌握它，即使看懂组合数学，代码也写不出来。
- 【角色/作用】核心：把"无逆元的除法"变成"移位 + 奇数逆元乘法"。
- 【天花板·最低达标线】验收动作：独立重写 init() 与 C()（不参考 main.cpp），并手算 C(6,3) mod 2^64 验证。通过标准：代码正确、数值一致；能解释 v≥64 时为什么为 0。

- 训练动作：复现代码 + 手算验证

**锚点 A12：复杂度分析与维度压缩**

## 7. 终局验收方式（与目标卡片一致）

1. **白纸推导**：不看任何资料，30 分钟内独立写出：图结构结论 → `ans=ΣC(n,i)C(m,j)j^i i^j` → Stirling/反演拆分（X(k,l)、Y(k,l)）→ 合并还原。通过标准：公式与 `solution.md` 完全一致、推导连续无缺步。
2. **代码验收**：独立重写 AC 代码（不参考 `main.cpp`），6 组官方样例输出 `1 2 16 28 150 1369` 全部正确。
3. **讲解验收**：向他人或录音讲清三个"为什么"：① 为什么零出度点必须孤立、左右非零个数不必相等；② 为什么维度 ≤65（k≥66 时 k!≡0 mod 2^64）；③ 为什么组合数必须用 2-adic 而非阶乘逆元。
4. **迁移自测**（加分项）：能指出若模数换成质数 1e9+7，代码哪几处需要改、为什么。

三项全过 = 目标达成；未全过 → 按回退预案回到对应锚点，不宣布完成。
