# J. Start to the End · 解题思路

## 一句话思路

图结构化简为：**选择非零出度点集合 + 两个任意映射**，得到
`ans = Σ_{i≥n-a} Σ_{j≥m-b} C(n,i) C(m,j) · j^i · i^j (mod 2^64)`。

朴素双循环 O(nm) 不可行，用 **Stirling 恒等式 + 二项式反演**把截断双重和拆成左右两个独立部分，维度压到 ≤ 65（因为模 2^64 下 k ≥ 66 时 k! ≡ 0）。

## 一、图结构分析

设非零出度左点集合 L'（|L'|=i）、非零出度右点集合 R'（|R'|=j）。

1. **零出度点必须完全孤立**：任何非零点的出边若指向零点，则一步就能走到零点，违反条件。所以零点既无出边也无入边。
2. **非零点的出边必须指向非零点**：
   - 每个左非零点出边指向 R' 中任意点：j 种选择，共 `j^i` 种；
   - 每个右非零点出边指向 L' 中任意点：i 种选择，共 `i^j` 种。
3. **约束**：左零点 `n-i ≤ a ⇒ i ≥ n-a`；右零点 `m-j ≤ b ⇒ j ≥ m-b`。

令 A = n-a，B = m-b（非零点数下界）：

```
ans = Σ_{i=A}^{n} Σ_{j=B}^{m} C(n,i) · C(m,j) · j^i · i^j   (mod 2^64)
```

约定 0^0 = 1；i=0 且 j>0（或反之）时对应幂为 0。

> 注意：左、右非零点的个数**不必相等**，图结构也**不必成环**（任意映射即可）。

### 样例验证（2 3 1 2）

`(i,j) ∈ {1,2}×{1,2,3}`：

| (i,j) | C(2,i)C(3,j) j^i i^j | 值 |
|---|---|---|
| (1,1) | 2·3·1·1 | 6 |
| (1,2) | 2·3·2·1 | 12 |
| (1,3) | 2·1·3·1 | 6 |
| (2,1) | 1·3·1·2 | 6 |
| (2,2) | 1·3·4·4 | 48 |
| (2,3) | 1·1·9·8 | 72 |

总和 = 150 ✓

## 二、加速：把双重和拆成左右独立

### 恒等式
1. （Stirling）`Σ_{t=0}^{k} (-1)^{k-t} C(k,t) t^i = k! · S(i,k)`，S 为第二类 Stirling 数，i<k 时为 0；
2. `Σ_k k! · S(i,k) · C(j,k) = j^i`。

### 拆分
定义截断二项式和：
```
F_l(t) = Σ_{i≥A} C(n,i) C(i,l) t^i
G_k(t) = Σ_{j≥B} C(m,j) C(j,k) t^j
```
做二项式反演：
```
X(k,l) = Σ_{t=0}^{k} (-1)^{k-t} C(k,t) F_l(t) = Σ_{i≥A} C(n,i) C(i,l) · k! S(i,k)
Y(k,l) = Σ_{t=0}^{l} (-1)^{l-t} C(l,t) G_k(t) = Σ_{j≥B} C(m,j) C(j,k) · l! S(j,l)
```
于是：
```
Σ_{k,l} X(k,l)·Y(k,l)
= Σ_{i≥A} Σ_{j≥B} C(n,i)C(m,j) [Σ_k k!S(i,k)C(j,k)] [Σ_l l!S(j,l)C(i,l)]
= Σ_{i≥A} Σ_{j≥B} C(n,i) C(m,j) · j^i · i^j     （与目标公式一致）
```

### 为什么维度 ≤ 65
模 2^64 下，k ≥ 66 时 `v2(k!) ≥ 64`，故 `k! ≡ 0`，贡献为 0。只需 k,l ∈ [0,65]，**与 n,m 无关**。

### 截断二项式和的闭式
利用 `C(n,i)C(i,l) = C(n,l)C(n-l,i-l)`：
```
F_l(t) = C(n,l) · t^l · [ (1+t)^{n-l} - S1(n-l, A-l-1, t) ]
```
其中 `S1(x,y,t) = Σ_{r=0}^{y} C(x,r) t^r`（部分二项式和）用帕斯卡递推：
```
S1(x,y,t) = (t+1)·S1(x-1,y-1,t) + C(x-1,y)·t^y
```
记忆化：x 只需从 n 递减到 n-65，状态 66×66。每组只需计算 t=0..65 的点值。

## 三、模 2^64 下算组合数

2^64 不是质数，**不能用阶乘逆元**（2 无逆元）。用 2-adic 分解：
- `C(n,m) = 2^v · (奇数部分)`
- `v = v2(m!) + v2((n-m)!) - v2(n!) = popcount(m) + popcount(n-m) - popcount(n)`（Legendre/Kummer 定理）
- 预处理 `di[i]`：1..i 去掉所有因子 2 后的奇数部分前缀积；`id[i]` 为其逆元（奇数在 2^64 下可逆）
- `C(n,m) = di[n] · id[m] · id[n-m] << v`；v ≥ 64 时为 0

## 四、复杂度

- 预处理：O(10^7)（di/id 数组）
- 每组：O(65² · log n) ≈ 10^5 次基本运算，t ≤ 10^3 可过 1 秒限制

## 常见误区

- 错误假设"非零点必须成环"或"左右非零个数相等"：实际上两个映射完全任意，个数可不等；
- 忘记零点必须无入边（否则一步走到零点）；
- 直接用阶乘逆元算组合数：2^64 下 2 无逆元，必须用 2-adic 分解；
- 双重循环 O(nm)：n,m ≤ 10^7 必然 TLE，必须用 Stirling/反演压缩维度。
